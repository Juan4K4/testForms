## Requisitos del Sistema

Para garantizar el correcto funcionamiento de la aplicación, su equipo debe cumplir con las siguientes especificaciones mínimas:

| Componente | Requisito Mínimo |
| :--- | :--- |
| **Sistema Operativo** | Windows 10 / Windows 11 |
| **Procesador (CPU)** | 1.3 GHz |
| **Memoria RAM** | 4 GB |
| **Espacio en Disco** | 2 GB |
| **Dependencias** | .NET 6/7 Runtime o .NET Framework 4.8 |
| **Red** | Conexión a internet activa |

## Instalación

Sigue estos pasos para instalar la billetera virtual en tu equipo:

1. **Descomprimir**: Extrae el archivo del proyecto (`.zip`) y abre la carpeta resultante.
2. **Ejecutar**: Localiza el instalador (`setup.msi` o `.msi`) dentro de la carpeta y haz doble clic para ejecutarlo.
3. **Ruta de instalación**: Se desplegará la ventana del instalador. Puedes cambiar la ruta de instalación, aunque se recomienda dejar la ruta por defecto. Haz clic en **Siguiente**.
4. **Confirmar**: El instalador estará listo y esperará tu confirmación. Presiona **Siguiente** (o **Instalar**) para confirmar.
5. **Finalizar**: Una vez completado el proceso, haz clic en **Cerrar**. 

> **Nota**: Al finalizar, se generará un **acceso directo** en tu escritorio desde el cual podrás ejecutar la aplicación.

## Funcionalidades de Usuario

### 1. Registro y Acceso
* **Crear Usuario**: En la pantalla inicial, selecciona "Registrarse", diligencia los campos con información verídica y el sistema validará la consistencia de los datos.
* **Ingreso**: Ingresa tus credenciales (usuario y contraseña) para acceder al menú principal según tu perfil.

### 2. Gestión de Perfil
* **Mis Datos**: Accede a esta sección para actualizar información personal como nombre, correo electrónico o contraseña (requiere ingresar la contraseña actual).

### 3. Transferencias
* **Enviar Dinero**: Dirígete a "Enviar dinero", ingresa el monto y el número de cuenta del destinatario. El sistema valida el saldo y genera un comprobante descargable.
* **Recibir Dinero**: Las transferencias entrantes se acreditan automáticamente, actualizan el saldo y quedan registradas en el historial.
* **Ver Movimientos**: Consulta el registro detallado de todas tus transacciones.

### 4. Solicitudes
* **Extractos de Cuenta**: Genera y descarga un resumen de tus movimientos financieros (envíos, recepciones, etc.) seleccionando el mes y año deseado en el apartado "Solicitudes".
* **Productos Financieros**: Solicita nuevos productos del banco diligenciando un formulario con datos personales, ingresos, egresos y nivel educativo. La solicitud será remitida para evaluación.

## Funcionalidades de Administrador

Los administradores cuentan con un módulo especial para la gestión de solicitudes de los clientes:

1. **Ingreso**: Accede con las credenciales de administrador proporcionadas por la entidad.
2. **Bandeja de Solicitudes**: Visualiza todas las solicitudes de productos bancarios pendientes.
3. **Gestión**: Utiliza la barra de búsqueda para encontrar solicitudes específicas por su `ID`.
4. **Aprobación/Rechazo**: Revisa los requisitos y aprueba o desaprueba las solicitudes de productos financieros según corresponda.
